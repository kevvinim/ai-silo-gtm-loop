# 게이트 테스트: 빨간불이 켜지는 것부터 확인

**왜:** 게이트는 우리를 지키는 안전장치다. 망가진 초안을 실제로 막는 것을 보기 전에는 통과 판정을 믿지 않는다.

**방법:**
- d0 초안 5개를 Notion 큐에 넣었다. 그중 1개는 일부러 규칙을 여러 개 어긴 불량 초안이다.
- 초안을 쓰지 않았고 어느 것이 불량인지 모르는 별도 에이전트가 플레이북 규칙만으로 판정했다.

| 초안 | 의도 | 게이트 판정 | 맞았나 |
|---|---|---|---|
| d0 · X · B3 · 고객사 성과 *(심어 둔 불량)* | 차단돼야 함: 가짜 "고객사 300곳·40%", "지금 안 하면 뒤처집니다 🔥🔥", `@openai @AnthropicAI` 태그 | **BLOCK**: 지어낸 고객과 성과, 압박 문구, 계정 태그 | ✅ |
| d0 · Threads · A1 · 단톡방 스크롤 | 통과 | PASS | ✅ |
| d0 · Threads · B1 · 휴가 간 그 사람 | 통과 | PASS (앵글 B는 원래 답글용이라 계획 밖이라는 메모) | ✅ |
| d0 · X · B2 · 5군데에 쌓이는 맥락 | 통과 | PASS (X 가중 길이 190/280) | ✅ |
| d0 · LinkedIn · C1 · 구독부터 결제 | 통과 | **BLOCK**: 플레이북에 적힌 인용문("…업무는 그대로")과 초안의 인용문("…조금도 달라지지 않습니다")이 다르고, 출처를 확인할 수 없음 | ❌ 오탐 |

**오탐 원인:**
- 초안의 인용문 자체는 원문 그대로였다([EO플래닛, 2026-09-17](https://eopla.net/magazines/46731)).
- 플레이북에는 줄인 문장만 있었고 출처 URL이 없었다.

**조치:**
- 게이트를 느슨하게 하지 않았다.
- 대신 플레이북 표에 원문 인용과 출처 URL을 넣었다([`loop/playbook.md`](../loop/playbook.md)).
- 규칙 2에 "인용문은 표의 원문과 글자까지 같아야 한다"를 추가했다.

**남은 것:** 수정한 플레이북으로 C1을 다시 판정하는 일은 다음 아침 실행 몫이다.

## 후속: 코드 게이트가 찾은 진짜 문제 (2026-10-24)
`npm test`의 인용 검사가 d0 LinkedIn 초안을 다시 잡았다.
- 원문에서 떨어져 있는 두 문장("일단 구독부터 결제합니다." / "한 달 뒤, 업무는 조금도 달라지지 않습니다.")을 인용부호 하나로 붙여 썼다.
- 원문을 바꾼 인용이므로 차단이 맞다.
- 에이전트 게이트의 사유("출처 확인 불가")는 틀렸지만, 결론(차단)은 맞았던 셈이다.

**조치:** 두 문장을 따로 인용하도록 초안을 고쳤다.
