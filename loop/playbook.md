## 링크 태그 (모든 링크)
```
https://ai-silo-check.vercel.app/go/d{일차}-{앵글}{번호}?utm_source={threads|x|linkedin|creator|community}&utm_medium={post|reply|dm}&utm_campaign=d{일차}&utm_content={앵글}{번호}
```
예: `/go/d1-A1?…&utm_content=A1`.
- **경로**(`/go/d1-A1`)는 Vercel 무료 플랜에서도 링크별로 셀 수 있게 하려고 넣었다. utm으로 나눠 보는 기능은 유료 플랜 기능이라는 지적이 있다(1차 출처 미확인).
- 공유로 들어온 방문은 `/t/{유형}/` 경로로, 진단을 끝까지 한 사람은 `/result/{유형}` 경로로 잡힌다.

## 규칙 = 게이트
초안이 규칙 하나라도 어기면 **Blocked**이고, Blocked 초안은 절대 게시하지 않는다.
1. 한국어로 자연스럽게 쓴다. "~드립니다"를 쌓지 않는다(korean-unslop 기준).
2. 숫자, 고객, 성과, 1인칭 경험을 지어내지 않는다.
   - 실제 인용은 출처와 함께 쓰거나 "자주 보이는 장면"으로 쓴다.
   - 인용문은 위 표의 원문과 글자까지 같아야 한다.
3. 제품이 출시됐다고 말하지 않는다. "만들고 있습니다"까지만 쓴다.
4. 하루 채널당 상한:
   - X, Threads: 게시물 3개, 답글 5개
   - LinkedIn: 게시물 1개
   - 모든 행동 사이에 20분 이상 간격을 둔다.
5. 같은 문장을 두 번 게시하지 않는다.
   - DM은 크리에이터 제안에만 쓰고, 건마다 사람이 승인한다.
   - 답글 3개 중 링크가 들어간 것은 최대 1개다.
6. 답글은 48시간 안에 올라온, 실제로 이 문제를 다룬 게시물에만 단다. 조언을 먼저 쓴다.
7. 우리와 소통한 적 없는 계정은 태그하지 않는다. 정치, 사건·사고, 비극 관련 글에는 답하지 않는다.
8. 압박하거나 과장하는 표현을 쓰지 않는다. "!!", 🔥, "지금 안 하면" 같은 말이 해당한다.
9. X 길이: 한글은 2, URL은 23으로 세어 280 이하.
10. LinkedIn은 자동 게시하지 않는다. 에이전트가 작성 창을 채워 두고 사람이 Post를 누른다.
